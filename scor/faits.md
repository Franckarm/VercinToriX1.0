# Faits pour essayer le raisonnement du ScoR

Le chat est un mammifère. Le dauphin est un mammifère. Le cheval est un mammifère.
Un mammifère est un animal. Un animal est un vivant. Une plante est un vivant.
Le requin est un poisson. Le saumon est un poisson. Un poisson est un animal.
Le dauphin n'est pas un poisson. Un poisson n'est pas un mammifère.
Un oiseau est un animal. Un oiseau est volant. Le moineau est un oiseau. Le manchot est un oiseau.
Le manchot n'est pas volant. Le chêne est une plante. Une plante n'est pas un animal.

Vercintorix est un langage. Un langage est un outil. Le cube est chromatique.
L'ADN est une mémoire. L'ARN est une hypothèse. Une hypothèse n'est pas une preuve.
Le diamant est une correction. Une correction est une protection.
La chauve-souris est un mammifère. La chauve-souris est volante.

Nixon est un quaker. Nixon est un républicain. Un quaker est pacifiste. Un républicain n'est pas pacifiste.
